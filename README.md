# 🚗 Sistema de Cadastro de Veículos

Projeto desenvolvido como desafio acadêmico utilizando tecnologias web.

## 📌 Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## ⚙️ Funcionalidades

- Cadastro de veículos
- Armazenamento em banco de dados
- Validação de campos obrigatórios
- Listagem de veículos

## 🗄️ Estrutura do Banco

Tabela `veiculos` com os seguintes campos:

- placa
- marca
- modelo
- ano_fabricacao
- ano_modelo
- cor
- combustivel
- quilometragem
- chassi
- renavam
- observacoes

## 🚀 Como executar

1. Instalar XAMPP
2. Copiar o projeto para `htdocs`
3. Iniciar Apache e MySQL
4. Acessar: http://localhost/veiculos


## 🧠 Observações

Projeto focado em prática de integração entre front-end e back-end utilizando PHP e banco de dados relacional.
